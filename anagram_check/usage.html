Anagram Checker Usage

Learn how to run the command-line anagram checker, compare two strings, and control how much input text is shown in the output.

Overview

The anagram checker compares two strings and reports whether they are anagrams after cleaning. It ignores configured characters, currently spaces, and applies configured case normalization.

If no strings are provided, the script runs built-in examples. If one string is provided without the other, the script prints an error.

Quick Start

Run the built-in examples

python3 anagram_check/main.py

Compare two strings

python3 anagram_check/main.py listen silent

Show command-line help

python3 anagram_check/main.py -h

Options

s1
The first string to compare. This argument is optional only when running the built-in examples.
s2
The second string to compare. Provide this whenever s1 is provided.
-h, --help
Show the command-line help text and exit.
--more-text CHARS
Show this many extra characters beyond the configured display length.
--show-full-text
Print complete strings instead of truncating long output.

Examples

Use quoted strings when input contains spaces

python3 anagram_check/main.py "Dirty room" "Dormitory"

Show more text for long input

python3 anagram_check/main.py "aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa" "aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa" --more-text 5

Show the full input strings

python3 anagram_check/main.py "long string one" "long string two" --show-full-text

The output includes emoji for quick scanning, but it also includes plain text such as are anagrams and are not anagrams. The result does not depend on color or emoji alone.
